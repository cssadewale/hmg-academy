CBT Pro — The Free Exam Platform

I built CBT Pro because I was tired of watching students prepare well but freeze on exam day because they had never sat a proper computer-based test. Now they can practise — for free — on the exact format WAEC and NECO use.

It was built on an Android tablet using Acode editor. That's not a limitation — that's a proof of concept. If you can think clearly, the tools don't matter.

Data Science Training Programme

Learn Data Science the Right Way

Most data science courses teach you tools. This programme teaches you thinking. Because a data scientist who can't reason about a problem clearly is just someone who knows how to run code.

I'm not a trainer who has never worked in the field. I am actively building ML models, shipping portfolio projects, and documenting the real journey — including the failures. That's what you'll learn from.

Enquire Now See My Portfolio

Module 1 — Python Foundations

Variables, data types, loops, functions, and the Pandas/NumPy stack. We start from the very beginning — no assumptions.

Module 2 — Data Analysis & EDA

Loading, cleaning, transforming, and visualising data. Non-graphical analysis always before graphical — the right workflow from day one.

Module 3 — Machine Learning

Classification, regression, and ensemble methods using Scikit-learn. Feature engineering, model selection, anti-leakage practices, and proper evaluation.

Module 4 — Explainability & Deployment

SHAP values, model interpretation, Streamlit dashboards, and publishing your portfolio on GitHub. Your work becomes public proof.
