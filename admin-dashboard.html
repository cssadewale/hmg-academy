What this dashboard controls

  • Create new CMS pages shown through `page.html?slug=...` immediately.
  • Override existing static pages such as `index`, `about`, `services`, `contact` by saving a CMS page with the same slug.
  • Unpublish/delete pages immediately through CMS status.
  • Upload images to Supabase Storage or local demo storage.
  • Change logo/founder images/site announcement without editing code.
  • Manage navigation entries and order.
  • Export/import CMS backup.

Important limitation explained

A static GitHub/Cloudflare site cannot physically rewrite HTML files without a redeploy or GitHub API token. HMG v6 solves “immediate updates” with a free Supabase CMS layer. The files stay static, while published CMS content loads immediately for visitors.

Deployment and live update model

  1. Deploy all static files to GitHub Pages or Cloudflare Pages.
  2. Create Supabase free project using `docs/SUPABASE_CMS_SETUP.md`.
  3. Configure `assets/js/config.js` with URL and anon key.
  4. Create an admin user in Supabase Auth.
  5. Login here, publish/edit pages, upload pictures and save settings.
  6. End users see changes immediately because public pages read the CMS data on page load.
No AI API: This dashboard does not call any AI API. All editing is human-controlled and storage uses free/static/Supabase tools.
