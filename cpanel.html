What is the purpose of cPanel?

Traditional cPanel is a web hosting control panel. It helps website owners manage hosting without command line knowledge.

  • Manage website files and folders.
  • Create domains, subdomains and redirects.
  • Manage DNS records and SSL certificates.
  • Create email accounts and webmail.
  • Manage databases such as MySQL.
  • Create backups and restore files.
  • View logs, bandwidth and statistics.
  • Configure cron jobs, security and server settings.

What this free HMG cPanel does

Because HMG Academy is a static/free-tool site, this panel focuses on realistic free operations.

  • Links all admin and deployment tools in one place.
  • Shows Supabase and local storage status.
  • Exports local operational data.
  • Tracks deployment checklist items locally.
  • Points to CMS, backup, media, pages and documentation.
  • Explains what must be done in GitHub, Cloudflare or Supabase.
