CBT Pro — Exam Platform
Live

A full computer-based testing system built entirely on an Android tablet using Acode editor. No frameworks — pure HTML5, CSS3, and Vanilla JavaScript. Backend powered by Supabase (PostgreSQL + Auth + RLS). Features: timed exams, per-student randomisation, flag-for-review, question navigator, auto-marking, AI explanations via Gemini API, result certificates, and a 4-tab teacher dashboard with CSV export.

Tech StackHTML5 · CSS3 · Vanilla JS · Supabase (PostgreSQL) · Gemini API · GitHub Pages

Student Performance Tracker v3
Live

A Streamlit dashboard with 4 interactive tabs designed for Nigerian secondary school teachers. Tab 1: Score summaries. Tab 2: At-risk thresholds and alerts. Tab 3: Topic-level analysis. Tab 4: Question-level breakdown. Uses Plotly for interactive charts. Designed from real classroom data needs.

Student At-Risk Predictor
Live

Random Forest classifier trained on synthetic Nigerian secondary school data with SHAP explainability. Identifies students at risk of poor performance before exams. Supports two modes: single-student input (form-based) and batch CSV mode for teachers processing an entire class. SHAP waterfall charts explain each prediction.

Model & StackRandom Forest · SHAP · Python · Scikit-Learn · Streamlit · joblib serialisation

Student Performance Advisor (AI)
In Progress

An LLM-powered advisory system that combines ML classification, SHAP explainability, and the Claude AI API to deliver personalised, conversational performance recommendations per student. Architecture: Scikit-learn ML backend → SHAP feature importance → Claude API advisory layer → Streamlit frontend → SQLite persistence. Dataset: UCI Student Performance (649 rows, Maths + Portuguese merged), four-class performance_tier target engineered from G3 scores.
