Deep Dive: Detailed Explanations of Key Systems

Why No Paid AI APIs?

Cost discipline is core. Paid APIs create recurring fees that make tools unaffordable for Nigerian schools and students. We use free alternatives (SQL.js, localStorage, rule-based logic where sufficient, open models when needed) so everything remains accessible at scale. AI is a force multiplier for clear thinking — never a cost centre.

Curriculum Design in the LMS Platforms

Every LMS follows a deliberate progression: Foundations → Core Skills → Application → Portfolio/Capstone. Role-based paths (e.g. Educator vs Data Scientist) ensure relevance. Weekly planners and active learning checks prevent passive consumption. All progress stored in browser localStorage for privacy and zero backend cost.

Parent Accountability in Virtual Home Schooling & LMS

Parents get visibility through dashboards (see interactive demo), weekly reports, and mastery certificates only issued on verified completion. This is not surveillance — it is partnership. Teachers and parents work from the same data.
