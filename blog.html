How to Add New Articles (for GitHub deployment)

This is a static site. To add a new post:
1. Edit the `posts` array in the <script> section of this blog.html file (add title, excerpt, category, date, fullContent).
2. Or create a new file like `post-your-title.html` and link it from here.
3. Commit and push to GitHub — it updates automatically.
Alternatively, send your writeup via WhatsApp and we can add it for you.
