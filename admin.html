Google Search Console Setup

  1. Go to search.google.com/search-console and sign in with Google account
  2. Click Add Property then URL prefix then enter https://hmgacademy.pages.dev
  3. Verify using HTML tag method - copy the meta tag and paste into index.html head then Deploy via GitHub
  4. After verification click Sitemaps and submit: https://hmgacademy.pages.dev/sitemap.xml
  5. Wait 24 to 72 hours then monitor Coverage and Performance tabs weekly
