🔗 Connect GitHub Gist for Cross-Device Sync

A GitHub Gist is a free, private cloud store. Your password (as a SHA-256 hash — never plaintext) and all CMS content will sync across every device you use. Free forever. No server needed.

1

Create a free GitHub account

Go to github.com → Sign Up (free). You likely already have one.

2

Create a Personal Access Token

Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under "Gist" permissions, enable Read and write. Copy the token.

3

Paste your token below and click Connect

Claude will create the Gist automatically. Your Gist ID will be saved in this browser as a reference only — your password hash and data live in the cloud.

Token needs: Gist → Read and write. Never stored in plaintext.

How to Create a GitHub Token

  1. Go to github.com/settings/tokens → Generate new token → Fine-grained token
  2. Set expiration to 1 year (or No expiration)
  3. Repository access → Only select repositories → pick your HMG Academy repo
  4. Permissions → Repository → Contents → Read and write
  5. Click Generate token, copy it immediately (shown once only), paste above
