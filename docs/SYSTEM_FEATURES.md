# HMG Academy v5 — System Feature Explanations

## 1. Tutor Marketplace
Search and filter tutors by subject, level and class type. Saves and compares tutors in browser localStorage. Booking goes through WhatsApp.

## 2. Course Catalogue
Searchable programme cards for exam prep, virtual schooling, data skills, international exams and school rollout. Enrolment interest saves locally.

## 3. Multi-role Portal
A role-based portal concept for learners, parents, tutors and schools. It gives clarity without needing a paid LMS backend.

## 4. Assessment Tool
Simple diagnostic that produces a score, readiness band and recommendation. It demonstrates HMG's insight-first teaching model.

## 5. Parent Dashboard
Tracks students, goals, milestones and notes. Useful for reports and parent accountability.

## 6. Assignment Tracker
Kanban-style board for homework, projects and tutor tasks. Statuses: To Do, In Progress, Submitted.

## 7. Attendance Log
Records session attendance for virtual classes, group programmes and bootcamps.

## 8. Certificate Generator
Creates printable certificates with local certificate IDs for webinars, bootcamps and LMS completion.

## 9. Virtual Classroom
Whiteboard demo, downloadable board image and free-tool session workflow.

## 10. Study Desk
Local study/help desk for questions, resource requests and lesson note needs. Escalates to WhatsApp.

## 11. Support Tickets
A WhatsApp-powered support workflow with a local ticket log.

## 12. Analytics Dashboard
Static analytics concept showing completion, attendance, at-risk alerts and certificate counts.

## 13. Reading Library
A reading habit and resource collection concept for young learners.

## 14. Career Pathways
Structured pathways for Data Analyst, Data Scientist, School Excellence, Study Abroad and Teacher Digital Skills.

## 15. Enterprise Suite
School rollout model for CBT, LMS, teacher training, analytics, certificates, backup and support.

## 16. Backup Center
Local-first storage with optional Supabase free-tier backup and offline JSON import/export.

## 17. No Paid AI API Policy
The site does not call paid AI APIs. This avoids recurring cost and keeps tools scalable for Nigerian schools.
