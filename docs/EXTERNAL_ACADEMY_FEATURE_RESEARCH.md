# External Academy Feature Research — v5

Additional large academy / LMS / classroom platforms reviewed for v5 inspiration included Khan Academy, Coursera, Udemy, Moodle, Outschool, Epic for Educators and Google Classroom.

## Features extracted and adapted

- Personalized learning and parent/teacher dashboards.
- Course catalogues and professional pathways.
- Teacher/classroom workflow and assignment management.
- Enterprise LMS concepts: integrations, privacy, accessibility and scalability.
- Live/self-paced class discovery and learner interest paths.
- Reading habits, badges, collections and class reports.
- Classroom analytics, differentiated instruction, grading/assignment workflows.

## HMG adaptation

HMG Academy cannot copy paid infrastructure or use paid AI APIs. Instead, v5 implements free/static equivalents:

- LocalStorage demos.
- Optional Supabase free-tier backup.
- WhatsApp workflow for forms and support.
- Static course catalogue.
- Browser-based certificate generator.
- Whiteboard demo.
- JSON export/import.
- Documentation-first deployment.

This preserves HMG's cost discipline while expanding enterprise readiness.
